# Future With You

一份可以装进手机里的情侣礼物。V0.2 在第一版愿望卡的基础上，加入了共同创造、随机约会、每日问答、回忆相册、时光胶囊和更完整的浪漫动效。

## V0.2 有什么

### 今天

- 显示在一起的天数与情侣昵称
- 约会灵感机：从 30 个灵感和未完成的自定义愿望中随机抽取
- 今日问题：两个人分别写下答案，慢慢形成只属于你们的对话档案
- 快速入口：新增愿望、浏览愿望与查看回忆

### 愿望

- 30 条内置愿望，覆盖日常、冒险、心动、成长和我们的家
- 支持新增她想做或我想做的事情
- 可填写分类、地点偏好、时长和计划日期
- 收藏、完成、左右滑动浏览
- 保存和完成时有浪漫庆祝动画

### 收藏与回忆

- 未完成收藏与已经完成的回忆分开展示
- 完成愿望时可以记录日期、感想和一张照片
- 照片在浏览器内压缩后存入本机
- 支持按全部、五大分类和共同创造筛选

### 我们

- 设置两个人的名字、纪念日和首页情话
- 创建写给未来的时光胶囊，到期后才能打开
- 浪漫花瓣、柔光、卡片呼吸和庆祝粒子效果
- PWA 安装入口与 iPhone 安装提示
- 导出和恢复完整备份
- #∞ 彩蛋：收藏至少 3 个愿望后解锁

## 运行

需要 Node.js 18 或更高版本。

~~~powershell
cd G:\gd\_pvp\_price\runs\qqj_lover
npm install
npm run dev
~~~

终端会显示本地地址，通常是 http://localhost:5173 。

构建正式版本：

~~~powershell
npm run build
npm run preview
~~~

## 安装到手机

PWA 的完整安装和离线能力需要 HTTPS。部署到 Vercel、Netlify、Cloudflare Pages 等静态站点后：

- Android / Chrome：使用页面中的安装入口，或浏览器菜单里的安装应用
- iPhone / Safari：点分享，再选择添加到主屏幕

## 数据与隐私

V0.2 是单设备原型。愿望、答案、照片与时光胶囊只保存在当前浏览器的 localStorage 中，不会上传到服务器。

- 更换浏览器、清理网站数据或卸载应用前，请先在我们的页面里导出备份
- 如果希望两台手机实时同步，需要在后续版本接入账号和云端数据库
- 从 V0.1 打开时，原有收藏与完成状态会自动迁移到 V0.2

## 项目结构

- src/app：应用入口与页面编排
- src/features：今天、愿望、收藏、我们与彩蛋
- src/components：卡片、弹窗、导航和动效
- src/data：内置愿望、每日问题和约会灵感
- src/domain：数据模型
- src/storage：本地数据适配与 V0.1 迁移
- public：PWA manifest、图标和离线缓存
